# Agents — User Stories

## Tom — owner

**S401.** As the owner, I want every seat started, seen, stopped and warned from Lys, so that herdr and Argus can be switched off.

**S402.** As the owner, I want to set a seat's words, variables, countdowns and schedules in one place and see what was actually delivered, so that overnight work runs without a second system.

**S411.** As the owner, I want every recurring seat path measured by a count proved to track real completion time and ratcheted only down, so that a performance claim cannot hide unmeasured work.

**S418.** As Tom, I want to send a message to any seat from the Sessions screen or the lys CLI and see it arrive in that seat as a real turn, so that I can talk to my agents from Lys.

**S419.** As the owner, I want an agent to use an app's store with its own grants, so that I can hand it work without lending it my sign-in.

**S420.** As the owner, I want to open Lys and see the network as a tree of machines and the agents running on them, and click one to watch its terminal, so that the state of the whole estate is one glance and one click away.

**S441.** As a person adding an agent, I fill one form and press once, and the agent is added, turned on, allowed on the computer I named and started in its folder, or I am told exactly which step was refused and what was done before it.

**S451.** As the owner, I want one command that gives a new agent its key and certificate on the computer it runs on and leaves the seat file where the profile expects it, so that no private key is made by hand or carried anywhere.

**S452.** As the owner, I want Stop to end a run and leave the agent able to start again, and the act that withdraws its certificate to be a separate, named, final one, so that I press Stop without fear.

**S453.** As the owner, I want to give an agent its roots in one choice and to review a profile's content once for all my agents, so that setting up a second agent is minutes, not a morning.

**S468.** As Tom, I want to give my AI the right to add people to the organisation and to change their details, and have it do so as itself, so that onboarding a person is something I can hand over whole.

**S469.** As Tom, I want every act my AI does with authority I gave it to be on my dashboard, with who, what and when, so that handing it everything never means losing sight of what was done in my name.

**S470.** As a person giving an AI authority, I want it never to hold or set anyone's password or sign-in, and never to be able to give more than I hold, so that delegating is safe by construction rather than by trust.

## Archie — an agent

**S403.** As an agent, I want to read and set my own variables with a revision, so that my focus survives a compaction and nobody overwrites it blind.

**S404.** As an agent, I want a reminder to carry the goal's words and the time left, so that I can plan the hour.

## An operator — a person running the estate

**S405.** As an operator, I want to attach to a seat's terminal from Lys when I need to look, so that I do not need a terminal workspace program to own the seats.

**S406.** As an operator, I want a supervised seat to keep working when its terminal, runner or identity service exits, so that a viewing or service failure does not end its conversation.

**S407.** As an operator, I want to upgrade Lys while an active seat streams and receives control replies, so that the same seat continues under one proven owner.

**S408.** As an operator, I want stored ownership and uncertain work to recover without replay and every failure to be proved by a signal-driven test, so that recovery does not invent success.

**S409.** As an operator, I want counted work per seat to stay flat at three times the real roster, so that supervision remains cheap as the team grows.

**S410.** As an operator, I want a deliberate stop to win over handover and the screen to name current ownership and unknown authority, so that I can trust what Lys says is running.

**S412.** As an operator, I want a long captured stream and terminal output to cost only its new bytes with no lost data, so that historical work cannot stall today's conversation.

**S413.** As an operator, I want one seat's ingest, delivery, registry and authority checks to ignore unrelated seats and history, so that three times the estate stays responsive.

**S414.** As an operator, I want every disk sync, checkpoint, queue and replay cost counted while keeping durable outcomes and old-install recovery, so that speed does not come from weakened safety.

**S425.** As an operator, I want the runner's own tests to be green on every run on the Linux box Lys moves to, so that a battery's red always names a real defect and never a race in a fixture.

**S427.** As an operator, I want every run that started while Lys was unreachable to appear under its person and agent with its calls and cost the moment Lys answers again, so that nothing an agent did in the storm case is missing from the record.

**S443.** As an operator running Lys's tests on a shared Mac, no runner or owner a test started is left running after the run, however the run ended, so the machine I share carries no stray session, harness or socket of a test long gone.

**S462.** As an operator whose machine runs the Lys gates, I want every test run to end the seat owners it started, so that a day of gates leaves no orphaned processes holding folders that no longer exist.

**S463.** As an operator, I want removing a seat's folder to end its owner, with one line saying why, so that an owner never runs on nothing and I have one act that ends it for good.

## A person starting an agent on their own computer — types one word and expects the agent to start, whether or not the Lys console is up

**S426.** As a person starting an agent on my own computer, I want lys claude to start my agent when the Lys console is off or unreachable, telling me plainly that it is, so that the one word works every time and I never have to open a terminal to work out why it did not.

**S442.** As a person on a fresh install, I can name my computer and its folder on the same form that adds my first agent.

**S444.** As a person running agents on several computers, I give one of my agents the right to set up and start my assistants once, and it does so on any of my computers without me at a screen, every act on the record as the agent's and every right one I can take back.

**S447.** As a person who trusts one of my agents to run my assistants, I give it the right to create agents for me, run them on my computer and set up their profiles with three plain choices on its file, once, instead of approving six steps for every assistant.

**S448.** As a person on the computer that runs Lys, I start my agent here like on any other computer, and I copy the line that connects Claude Code or Codex to it from the agent's own page instead of assembling it from help text.

**S449.** As a person whose agent registers agents for me, I want a crash in the middle to leave at most an agent with no rights that the next try finishes, never rights on an agent that does not exist, so that nothing invisible accumulates in my name.

**S450.** As a person whose agent sets up an assistant for me, I want it to be able to start that assistant without me at a screen, and I want to see on my dashboard every agent it registered or started, with Stop beside each, so that nothing acts in my name that I cannot see and stop.
