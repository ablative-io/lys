# Lys: the journeys people and seats wait on, and today's numbers (5 October 2026)

Tom, 5 October, about 17:01 and 17:03, after the article at ablative/docs/claude-ai-faster.md: "do we want to
basically sort of like implement that across every project?" and "let's have a look at all of our processes...
it doesn't have to be like everything at once, but... everything that's working currently."

The method taken from the article: each journey gets one number; a check holds the number on every change and it
may only go down; where clock time is noisy an exact count stands in for it. This page is Lys's list. Cambium,
Dot and haematite write the same page in their own repositories. A figure here was read from a log or a record;
where none was read the line says "not measured". Nothing is assumed.

## The slowest, and why, as far as it has been read

The test run is two thirds of the battery. Its own spread, 511 s to 1,480 s on the same machine, follows the load
on Tom's Mac (150 to 200 on 5 October afternoon) more than the code, so clock time cannot be the held number
there. The upgrade journey is worse than slow: it is not a journey yet, because sessions do not survive it.

## The exact count a check could hold, for each

- Installed build: seconds from fire to INSTALLED is noisy; the count is the number of crates compiled in the
  release leg from a warm target for a one-file change. Not measured.
- Proven: the number of tests over two seconds (nextest marks them), and the number of full flushes the whole
  test run makes. Not measured; the 3 October defect was a full flush per leaf, and nothing holds that count now.
- Upgrade: the number of live sessions ended by an install. Today it is all of them; the number to reach is 0.
- First call: input tokens on a run's first call, and the share of them read from the cache on the second.
  58,170 on the first; on the next start 53,647 read from the cache and 4,519 new.
- A page opens: the number of requests the page makes and the bytes it receives. Not measured.
- Signing in: the number of round trips between the form and the first screen. Not measured.

## What costs most per change in the working loop

One battery per piece: 15 min 48 s when the machine is quiet, and it needs 65 GB free on Tom's Mac, which on
5 October afternoon stood at 61 to 64. Before it, the whole-tree checks on Dean's laptop. After it, the walk
with pictures by hand, not measured.
