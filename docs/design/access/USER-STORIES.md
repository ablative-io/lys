# Access — User Stories

## Tom — owner and administrator

**S301.** As the owner, I want to say in one grant that Archie may stop seats by draft, so that an agent acts within its grant and I approve the rare act without a second system.

**S302.** As the owner, I want one screen that shows who can do what in every product, so that permissions are not a nightmare to operate.

**S303.** As the owner, I want a product deploy that widens a role to wait for me, so that nobody holds more because a release shipped.

## Hermes — a product lead (liminal)

**S304.** As a product lead, I want one library that verifies a pass, reaches through parents and refuses in one shape, so that I do not implement permissions a fourth way.

**S305.** As a product lead, I want a device to hold export and import grants on a link, so that federation has a holder.

## Archie — an agent

**S306.** As an agent, I want a refusal to name the grant I need and where to ask, so that I ask the right person once.

**S307.** As an agent, I want a by_draft act to be held and done after approval without my doing it twice, so that I never work around a draft.

## A clinician — a person in a hospital workspace

**S308.** As a clinician, I want a private place reached only by those granted it, so that a new colleague does not see every ward's channel on their first day.
