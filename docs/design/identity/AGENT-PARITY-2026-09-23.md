# Agent parity with the screen, and where permission decides who (Tom, 23 September 2026)

Recorded by Archie from Tom's words in Dot, 10:19 to 10:21 Melbourne, during the Cambium seat tool review (Cambium MCP-003). This is input to the directory and permission rows of IDENTITY-001 (rows 04 to 06). It is not a grant design.

## What Tom ruled

- "If a human can do it through the UI, then I want an agent to be able to do it." Full parity: making rooms, tagging posts, starting, joining and controlling huddles, provisioning seats, and the calendar all get agent tools.
- "Can agents start a new seat? Yes, they should be able to. Should everybody be able to? No." So whether an agent may do something is a permission question, not a question of what the tools offer.
- Removing a note "obviously needs to be addressed". It is a Cambium door gap, not a lys one.

## Examples Tom gave, not yet decided ("not necessarily things that we've decided on just yet")

- Once identity, access and permissions are online, an agent might be given abilities with an assignment or a project.
- An agent might be allowed to provision new seats within a budget it is given.
- Private notes, and sharing them, within the permission tree, "probably a thing for later on".

## What this means for lys, as questions for the rows, not answers

1. The tools expose every act, and lys decides who may do it. The grant model must be able to name any act a person can do on a screen. Is that per route family (for example "provision a seat"), or finer?
2. Can a grant be bounded, not only allowed or refused (for example a budget on seat provisioning)? If so, who meters it, and where is the count kept?
3. Can a grant come with an assignment or a project, and does it end with the assignment?
4. Private and shared notes need a per-record audience inside the tree. Is that a lys grant, or Cambium's own admission?
5. Until lys is live, the Cambium door's current authorization stands. The one change already authorized is a seat setting its own notification table (Cambium CORE-029, Tom 10:00). Nothing else is widened.

These stay with the human-rooted rule of 22 September: every grant traces to a responsible human, and an agent exercises or delegates only an explicit subset of what that human holds.
