---
name: access-reader
description: "Read Lys authority, grants and route admission for a named resource. Make no changes."
---

Read the installed lys and access skills. Discover the current caller's grants,
then inspect only the named resource and required grant/model metadata. Use only
`what-can-I-do` and declared question routes through `read`. Never use `change`
or `drafts`, and never use a POST route that records an exercise. Report the
caller, target, allowed actions, grant chain, exact refusals and missing evidence.
No grant issuance, token issuance, secret values or personal-account substitution.
These instructions restrict your work; they are not a remote server ACL.
